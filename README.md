# ✈️ 세계 여행 비행기 — 유치원 교통기관 놀이

1인칭 파일럿 시점의 오픈월드 비행 놀이 프로그램입니다.
조종석에 앉아 계기판을 보며, 창문 밖 하늘과 바다와 **세계 24개 도시**를 구경하고
도시마다 여권 도장을 모읍니다.

**키보드·터치는 물론, 카메라로 몸을 인식해서 온몸으로 조종할 수도 있고,
같은 코드를 넣으면 친구와 같은 하늘에서 함께 날 수 있습니다.**

## 실행 방법

인터넷이 되면 **<https://cbrnlee.github.io/world-flight/>** 로 바로 열면 됩니다.

인터넷이 없는 교실이라면 `index.html` 파일을 **더블클릭**하세요. 설치도 필요 없습니다.

> 크롬(Chrome)이나 엣지(Edge)에서 가장 잘 보입니다.
> 전체 화면(<kbd>F11</kbd>)으로 하면 더 실감 납니다.

**🎥 몸으로 조종하기가 켜지지 않으면** 로컬 서버로 열어 주세요.
(브라우저에 따라 파일을 직접 열었을 때 카메라를 막는 경우가 있습니다.)

```bash
cd "비행기 운전" && python3 -m http.server 8123
```

그다음 브라우저에서 `http://localhost:8123` 에 접속하세요.

## 다른 곳에 올리고 싶다면

먼저 **파일 하나로 묶습니다.** CSS·JS가 모두 HTML 안으로 들어가서, 어디에 올려도
파일 한 개만 있으면 됩니다.

```bash
cd "비행기 운전" && python3 build.py
```

만들어지는 것:

| 파일 | 쓰임새 |
|---|---|
| `dist/세계여행비행기.html` | **웹에 올리거나 그냥 더블클릭.** 완전한 한 장짜리 파일 (약 123KB) |
| `dist/artifact.html` | claude.ai Artifact 로 올릴 때 쓰는 판 |

### 어디에 올릴까

| 방법 | 주소 | 카메라 | 준비 |
|---|---|---|---|
| **GitHub Pages** ← 지금 쓰는 곳 | `cbrnlee.github.io/world-flight` | ✅ 됨 | 깃허브 계정, 무료 |
| **Netlify Drop** | `이름.netlify.app` | ✅ 됨 | 계정 없이 파일 끌어다 놓기 |
| **Claude Artifact** | `claude.ai/code/artifact/...` | ⚠️ 막힐 수 있음 | 이미 올려 둠 |

> **카메라는 `https://` 주소에서만 켜집니다.** 위 세 곳 모두 https 이지만,
> Artifact 는 페이지가 액자(iframe) 안에서 열리기 때문에 카메라가 막힐 수 있습니다.
> 그때는 프로그램이 "이 페이지에서는 카메라를 쓸 수 없어요"라고 알려 주고,
> 키보드·터치 조종은 그대로 됩니다.
> **유치원에서 카메라 놀이를 하려면 GitHub Pages / Netlify 를 쓰거나,
> `dist/세계여행비행기.html` 을 내려받아 컴퓨터에서 바로 여세요.**

```bash
cd "비행기 운전"

## 조종 방법 ② 🎥 몸으로 조종하기 (카메라)

화면 위쪽 **🎥 몸으로 조종** 버튼을 누르면 카메라로 온몸을 인식합니다.

| 몸동작 | 비행기 |
|---|---|
| 🙆 **팔을 기울이면** | 그쪽으로 돌아요 — **좌우** |
| 🧍 **팔을 나란히** 하면 | 수평 비행 — **수평** |
| 🙌 **팔을 위로 / 아래로** | 올라가고 내려가요 — **고도** |
| 🦸 **가까이 오거나 키를 크게** / 무릎을 굽히면 | 빨라지고 느려져요 — **속도** |

### 준비 순서 (2단계, 약 6초)

1. **배경 기억 (3초)** — "카메라 앞에서 잠깐만 비켜 주세요" 안내가 나오면 화면 밖으로 비켜 주세요.
2. **기준 자세 기억 (3초)** — "팔을 옆으로 쭉 펴고 서 주세요" 안내가 나오면 **T 자**로 서 주세요.

그다음부터 바로 몸으로 조종됩니다. 왼쪽 아래에 실루엣 미리보기가 나오고,
노란 선이 두 팔, 분홍 점이 머리입니다.

### 잘 안 될 때

| 증상 | 해결 |
|---|---|
| 사람이 안 잡힘 | 미리보기의 **민감도**를 낮춰 보세요(숫자를 작게) |
| 배경까지 사람으로 잡힘 | 민감도를 **높이고**, **🖼 배경** 버튼으로 배경을 다시 기억 |
| 조종이 자꾸 한쪽으로 쏠림 | T 자로 서서 **🧍 기준** 버튼을 다시 누르세요 |
| 도중에 카메라가 흔들림 | **🖼 배경** → **🧍 기준** 순서로 다시 잡으세요 |

**좋은 환경:** 카메라를 삼각대나 책상에 **고정**하고, 아이가 **두세 걸음 뒤로** 서서
온몸이 화면에 들어오게 합니다. 배경은 단순할수록 좋고, 조명이 갑자기 바뀌지 않게 해 주세요.
한 번에 **한 명만** 화면에 들어오는 것이 가장 잘 됩니다.

> 🔒 **개인정보** — 카메라 영상은 이 컴퓨터의 브라우저 안에서만 계산에 쓰입니다.
> 저장되지도, 인터넷으로 전송되지도 않습니다. 서버로 아무것도 보내지 않습니다.

> 키보드나 화면 버튼을 만지면 그 순간에는 손 조작이 우선이고,
> 손을 떼면 다시 몸동작이 조종을 이어받습니다.

## 조종 방법 ③ 🌐 친구와 함께 날기 (온라인)

**같은 네 자리 코드**를 넣으면 서로 다른 컴퓨터에 있어도 같은 하늘에서 만납니다.
친구의 비행기가 창밖에 보이고, 그 위에 이름표와 거리가 함께 떠요.

1. 한 사람이 **🌐 함께 하기 → 새 코드**를 눌러 코드를 만듭니다. (예: `7777`)
2. 그 코드를 친구에게 알려 줍니다.
3. 둘 다 같은 코드를 넣고 **함께 날기**를 누르면 끝. 화면 오른쪽 아래에 친구 목록이 뜹니다.

교실 여러 곳에서 동시에 놀 때는 **반마다 다른 코드**를 쓰면 됩니다.

> 🔒 **주고받는 것은 별명과 비행기 위치뿐**입니다. 카메라 영상은 절대 나가지 않습니다.
> 다만 누구나 쓸 수 있는 공개 중계소를 거치므로 **코드를 아는 사람은 들어올 수 있습니다.**
> 실제 이름 대신 별명을 쓰게 해 주세요.

### 어떻게 만들었나

깃허브 페이지는 정적 사이트라 서버를 둘 수 없습니다. 그래서 누구나 쓸 수 있는
**공개 MQTT 중계소**에 WebSocket 으로 붙어 위치를 주고받습니다.
MQTT 클라이언트도 라이브러리 없이 직접 만들었습니다(`js/mqtt-lite.js`, QoS 0 전용).

- 위치는 **1초에 열 번** 보냅니다. 받는 쪽은 그대로 찍지 않고 **추측 항법**으로 이어
  그려서, 10번/초로 받아도 60번/초처럼 부드럽게 움직입니다.
- 보내기는 화면 그리기와 **따로** 돕니다. 창을 뒤로 보내 두어도 친구 눈에는 계속 날아요.
- 중계소가 막히면 **다음 중계소로 자동으로 옮겨** 붙습니다(3곳 준비).
- 7초 동안 소식이 없는 친구는 목록에서 사라집니다.

```

### 신체 인식은 어떻게 동작하나요

머신러닝 라이브러리를 쓰지 않고 직접 만들었습니다. 덕분에 **인터넷 없이, 다운로드 없이**
바로 돌아갑니다.

1. 카메라 화면을 160×120 으로 줄여서 처리합니다(가볍고 잡음에 강함).
2. 사람이 없을 때의 **배경을 평균 내어 기억**합니다.
3. 매 프레임 배경과 색이 다른 픽셀을 모아 **실루엣**을 만들고, 잡티를 지웁니다.
4. 실루엣에서 세 가지를 잽니다.
   - 세로줄별 무게중심의 **양쪽 끝** = 두 손 → 기울기(좌우) · 높이(고도)
   - 가운데 줄들의 **꼭대기** = 머리 → 화면에서의 키 높이(속도)
5. 기준 자세(T 자)와 비교해서 −1 ~ +1 조종 신호로 바꾸고, 부드럽게 이어 줍니다.

머리는 **가운데 25% 줄에서만** 찾기 때문에, 팔을 옆으로 올려도 속도가 흔들리지 않습니다.
반대로 손 높이는 머리를 기준으로 재기 때문에, 앉거나 서도 고도가 흔들리지 않습니다.

### 도시를 더 넣고 싶다면

`js/world.js` 의 `CITY_DATA` 배열에 항목을 하나 추가하고,
`build` 자리에 랜드마크를 만드는 함수를 적어 주세요.
`box`(상자) · `fru`(원뿔대·기둥·피라미드) · `disc`(원판) · `rect`(바닥면)
네 가지 도형만으로 대부분의 랜드마크를 만들 수 있습니다.

```js
{ id: 'hanoi', name: '하노이', country: '베트남', flag: '🇻🇳',
  landmark: '한기둥 사원', pos: [x, z], tall: 0.8, seed: 1717,
  grass: [130, 175, 100],
  walls: [[220,205,190], [190,180,170]],
  fact: '아이들에게 들려줄 한 줄 이야기',
  real: '조금 더 자세한 이야기',
  // noBuild: function (x, z) { return ...; }   // 비워 둘 자리가 있으면
  build: function (g) { box(g, 0, 0, 0, 200, 60, 40, [200,180,150], 0, true); } }
```

여권의 총 개수(`/24`)는 도시 수에 맞춰 자동으로 바뀝니다.
